<h2><a href="https://www.geeksforgeeks.org/problems/geeks-training/1">Geek's Training</a></h2><h3>Difficulty Level : Difficulty: Medium</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18.6667px;">Geek is attending a training program for <strong>n </strong>days. Each day he must perform exactly one of three activities: Running, Fighting, or Learning. Each activity earns a certain number of merit points, which can differ from day to day. <br></span><span style="font-size: 18.6667px;">To improve all his skills, Geek cannot perform the same activity on two consecutive days.<br></span><span style="font-size: 18.6667px;">Given a 2D matrix <strong>mat[][] </strong>of size n × 3, where for the i-th day:</span></p><ul><li><span style="font-size: 18.6667px;">mat[i][0] is the merit points for Running</span></li><li><span style="font-size: 18.6667px;">mat[i][1] is the merit points for Fighting</span></li><li><span style="font-size: 18.6667px;">mat[i][2] is the merit points for Learning</span></li></ul><p><span style="font-size: 18.6667px;">Return the maximum total merit points Geek can earn over the n days.</span></p><p><span style="font-size: 14pt;"><strong>Example:</strong></span></p><pre><span style="font-size: 18.6667px;"><strong>Input: </strong>mat[][] = [[8, 7, 1],[9, 2, 1]]<strong>
Output: </strong>16<strong>
Explanation: </strong>Picking the best activity on day 1 (Running, 8) blocks Running on day 2,
so the best he could then get is Fighting (2), giving 10.
Instead, Geek does Fighting on day 1 (7) and Running on day 2 (9), giving 7 + 9 = 16.</span></pre><pre><span style="font-size: 18.6667px;"><strong>Input: </strong>mat[][] = [[2, 5, 3],[6, 4, 1],[3, 7, 2],[4, 4, 9]]<strong>
Output: </strong>27<strong>
Explanation: </strong>One optimal plan is Fighting (5), Running (6), Fighting (7), Learning (9).
No activity repeats on consecutive days, and the total is 5 + 6 + 7 + 9 = 27.</span></pre><pre><span style="font-size: 14pt;"><strong>Input:</strong> mat[][]= [[4, 2, 6]]
<strong>Output: </strong>6
<strong>Explanation: </strong>With only one day there is no consecutive-day restriction, so Geek simply picks the best activity, Learning, and earns 6 points.</span></pre></div><p><span style=font-size:18px><strong>Company Tags : </strong><br><code>NPCI</code>&nbsp;<br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Dynamic Programming</code>&nbsp;<code>Arrays</code>&nbsp;
